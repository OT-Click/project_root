## 0. Краткое резюме
Продукт представляет собой систему для соискателей, позволяющую **ускорить процесс отклика на вакансии в Telegram до 15 секунд**. Система состоит из Telegram-бота для приема вакансий, бэкенда на основе событийно-ориентированной архитектуры (Event-Driven) для обработки вакансий и подбора резюме, а также интерфейсов для пользователя (Telegram Mini App + SPA) для отслеживания статусов. Основная цель - максимально автоматизировать и ускорить рутинные задачи соискателя при поиске работы.

---

## 1. Цели продукта и метрики
| Метрика | Цель |
|---------|------|
| Среднее время до отправки отклика | ≤ 15 с |
| Доля обработанных вакансий | ≥ 20 % |
| Trial → Paid Conversion | ≥ 30 % |
| Churn 30 дней | ≤ 8 % |

---

## 2. Персоны и сценарии
1. **Соискатель** — пересылает vacancy‑сообщения боту, отслеживает статусы своих откликов в Mini App/SPA, загружает CV.
2. **Рекрутер (опционально, для расширенной версии)** — вручную меняет статусы вакансий кандидатов в Chrome‑плагине, видит общую воронку.

*Подробные Gherkin‑истории User Stories и сценарии использования описаны в файлах `/features/*.md`.*

---

## 3. Функциональные требования (MVP)
| № | Функция | Приёмочный критерий | Пользовательская ценность |
|---|---------|---------------------|--------------------------|
| 1 | Прием вакансии ботом | Бот получает пересланное сообщение, распознает его как вакансию, отвечает пользователю уникальным ID (тикетом). | Быстрый и удобный способ занести вакансию в систему. |
| 2 | Парсинг данных вакансии | Система автоматически извлекает ключевую информацию из текста вакансии (e.g., контакты, название). | Избавляет от ручного копирования данных. |
| 3 | Подбор релевантного CV | Система автоматически подбирает наиболее подходящее CV пользователя для вакансии. | Ускоряет подготовку к отклику. |
| 4 | Автоматический отклик | Система отправляет отклик (сообщение + CV) контакту из вакансии через Telegram. | Экономит время на отправку однотипных сообщений. |
| 5 | Отслеживание статусов | Пользователь видит актуальный статус своего отклика ("Отправлено", "Отвечено" и т.д.) в Mini App/SPA в реальном времени. | Прозрачность процесса, понимание текущей ситуации по каждой вакансии. |
| 6 | Загрузка CV | Пользователь может загрузить свое резюме в формате PDF через интерфейс. | Централизованное хранение резюме для автоматических откликов. |
| 7 | (Post-MVP) Управление подпиской | Пользователь может выбрать и оплатить тарифный план. | Доступ к расширенным возможностям сервиса. |

---

## 4. Расширенные функции (Post-MVP)
- Автоматическое изменение статуса на "Отвечено" при ответе рекрутера
- Изменение статуса на "Interview"/"Offer" пересылкой хештега
- Chrome-плагин для ручного обновления статусов (для рекрутера)
- Возможность отправки отклика по Email при наличии адреса
- Парсинг вакансий из HTML-фрагментов (через Chrome-плагин)

---

## 5. Нефункциональные требования (Ключевые)
- **Производительность:** Время от пересылки вакансии боту до отправки отклика не должно превышать 15 секунд для MVP. Скорость обновления статуса в интерфейсе - не более 15 секунд.
- **Надежность:** Система должна быть доступна и корректно обрабатывать запросы (SLA будет определен отдельно, см. Открытые вопросы). Базовая отказоустойчивость для MVP.
- **Масштабируемость:** Архитектура должна позволять горизонтальное масштабирование компонентов при росте нагрузки.
- **Безопасность:** Данные пользователей должны быть защищены. Аутентификация и авторизация через стандартные протоколы.
