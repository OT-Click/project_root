## Feature: [[F04] Смена статуса пересылкой сообщения](https://github.com/OT-Click/project_root/issues/57)

_**_As a_** соискатель, **_I want to_** переслать сообщение рекрутера боту и тем самым обновить статус вакансии, **_So that_** я мог быстро фиксировать этапы собеседования._

### Rule: Статус определяется хештегом в начале сообщения
- `#interview` → «Interview»
- `#offer`      → «Offer»

### Scenario: [[S04.01] Обновление статуса пересланным сообщением](https://github.com/OT-Click/project_root/issues/55)

- **_Given_** соискатель получил предложение интервью в личном чате
- **_When_** он пересылает сообщение с хештегом `#interview` боту
- **_Then_** Web‑hook анализирует текст, извлекает Vacancy ID по контексту диалога
- **_And_** статус Vacancy меняется на «Interview»
- **_And_** бот отвечает «Статус обновлён на Interview»
- **_And_** карточка в SPA / Mini App перемещается в колонку «Interview»

### Scenario: [[S04.02] Ошибка сопоставления Vacancy ID](https://github.com/OT-Click/project_root/issues/56)

- **_When_** соискатель пересылает сообщение без релевантного контекста
- **_Then_** бот отвечает «Не удалось определить вакансию, укажите ID вручную»
