## Feature: [[F08] HTML‑парсер вакансий](https://github.com/OT-Click/project_root/issues/66)

_**_As a_** соискатель, **_I want to_** вставлять HTML описания вакансий, а система — автоматически извлекала структуру и продолжала пайплайн, **_So that_** я мог обрабатывать вакансии с job‑бордов._

### Background

- **_Given_** пользователь авторизован в Chrome‑плагине

### Scenario: [[S08.01] Вставка HTML и автопарсинг](https://github.com/OT-Click/project_root/issues/65)

- **_When_** пользователь нажимает кнопку «Вставить HTML» и отправляет фрагмент страницы
- **_Then_** плагин публикует сообщение в очередь `vacancy.raw` с типом="html"
- **_And_** сервис ingest извлекает не менее 80% полей Vacancy из HTML контента
- **_And_** статус вакансии устанавливается «Parsed»
- **_And_** бот отвечает тикетом с ID вакансии
